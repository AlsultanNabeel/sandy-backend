# خطوط ساندي العربية

مولّدة، مش مكتوبة بالإيد. لا تعدّلها — أعِد توليدها.

## ليش موجودة

لفچل ما عندها إلا خط عربي واحد مدمج، وبمقاس واحد: ستّة عشر بكسل. فالمالك طلب
تحكّم بحجم الكتابة ع الشاشة، وما كان في طريقة صادقة أعطيه إياها — «حجم» يغيّر
الرقم وما يغيّر الشكل أسوأ من غياب الخيار.

فولّدنا نفس الخط بمقاسين زيادة.

## إعادة التوليد

    npm i lv_font_conv@1.5.2
    R="0x20-0x7F,0x600-0x6FF,0xFE70-0xFEFF"
    for sz in 24 32; do
      lv_font_conv --font DejaVuSans.ttf --range "$R" --size $sz \
        --bpp 4 --format lvgl --no-compress --lv-include lvgl.h \
        -o sandy_font_ar_${sz}.c
    done

## عن المدى

`0x600-0x6FF` هو الحروف العربية، و`0xFE70-0xFEFF` أشكال العرض-ب — اللي بتستعملها
لفچل وقت تشبيك الحروف. أشكال العرض-أ (`0xFB50-0xFDFF`) مشيلة عمدًا: ست مية رمز
روابط ما بتستعملها، وكانت بتكبّر الملفين لأكثر من ضعفهم.
